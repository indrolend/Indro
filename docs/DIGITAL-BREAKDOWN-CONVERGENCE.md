## Reusable pattern

Resolve repositories and revisions; compile an effect-checked Indro plan; run a
bounded task through CommandHUD in an isolated worktree; verify focused and full
suites; promote the exact verified patch; reuse immutable evidence for proof and
impact; write provenance-bearing semantic conclusions; checkpoint; generate a
handoff; and execute its next action as a new recorded operation. Keep domain
truth in the domain repository and keep execution evidence in CommandHUD.

## Unsupported or incomplete

Indro's plan type system does not yet treat repository revisions or cross-repo
dependencies as authority-bearing types; this example passes them as strings or
paths. CommandHUD cannot yet register an arbitrary existing worktree without a
project-identity concern. Brokeman has checkpoint and handoff operations but no
generic resume dispatcher. Visual parity, graphical acceptance, live MCP/remote
interoperability, performance, and build-time comparisons remain unmeasured.
