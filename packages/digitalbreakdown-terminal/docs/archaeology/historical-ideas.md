## Leads not recovered as original history

- **Rolling Clipboard:** the exact phrase appears only in the 2026-10-18 handoff/current Codex rollout. Searches of named repositories, `D:\hud`, active and archived Codex JSONL sessions, and attachments found no older match. CommandHUD does implement clipboard projection (`deliverShellProjection`, compact handoff, evidence projection) and the retirement audit records latest/all-history clipboard actions. The original Rolling Clipboard design is therefore **unrecovered**; any consolidated design is class D.
- **Cell mitosis:** an earlier user-authored mitosis metaphor was recovered, but it concerns self-describing HTML/compiler structure rather than autocomplete. Treat the mapping from that metaphor to terminal completion branching as class D; the explicit autocomplete behavior is class A only from the current handoff.
- **Four-line Indro slogan:** the handoff is a compressed paraphrase of the documented Indro laws, not their exact text. Git attributes the canonical laws to commit `460c4b5679689438ec136d6b65098565963319f2`, 2026-09-16: “Stable process -> one word,” “Inferable workspace context is implicit,” “Consequential authority changes remain explicit,” and “Evidence is ambient.” No earlier direct user message containing the four lines was recovered, so origin attribution remains uncertain.
- **Sprite sheets:** searched sources did not yield a terminal sprite-sheet implementation. Braille rendering is real in MonumentWorld; WebGL extrusion and cell animation are real; sprite sheets remain unverified.

## Newly recovered visual source rules

The Basic Browser SPA conversation supplies a compact, reusable transition contract: a stable **from** object and stable **to** object must be prepared before animation; only the object surface transitions; final DOM/state commits after the transition; repeated navigation keeps the latest requested destination rather than serially replaying stale inputs. The terminal's evidence expansion reuses only the first three rules: explicit source identity, compact-to-detail transformation, and a bounded stage around the participating surfaces. It does not import SPA navigation, router, or execution behavior.
